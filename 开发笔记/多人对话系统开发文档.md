# 多人对话系统开发文档

> 本文档定义多人对话展示场景的设计方案、数据结构与实现规范，供开发与后续扩展参考。

---

## 一、设计定位

- **用途**：当游戏需要进行多人对话（联盟成员、NPC、玩家）时，跳转到独立对话场景播放对白。
- **模式**：数据驱动。所有对白内容写在各 `data/dialogue/*.gd` 配置文件中，逻辑代码不写死文案。
- **布局**：玩家在**右侧**，其余 NPC 在**左侧**，中间为聊天对白框（类 IM 群聊布局）。
- **推进**：普通对白整句直接显示，默认时间后自动跳下一条，也支持**空格**与**鼠标点击**提前推进；带玩家选项的行**不自动跳转**，必须由玩家选择后才跳转。全程显示**按键操作提示**。

---

## 二、数据模型

### 2.1 角色表 `data/dialogue_characters.gd`

```gdscript
# data/dialogue_characters.gd
extends Node

const characters = [
    {"name": "moran",  "display": "墨染",  "color": Color(0.49, 0.61, 1.0)},
    {"name": "boy",    "display": "Obaby", "color": Color(1.0, 0.61, 0.42)},
    {"name": "player", "display": "我",    "color": Color(0.43, 0.86, 0.54), "side": "right"},
]
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | String | ✓ | 角色唯一标识（对白行通过 `speaker` 引用） |
| `display` | String | ✓ | 显示名（头顶/对白框显示） |
| `avatar` | String | 可选 | 头像图片 URL/路径；存在则优先使用 |
| `color` | Color | ✓ | 无头像时色块颜色（兜底） |
| `side` | String | 可选 | 布局方位：`right` 靠右（玩家），缺省为 `left` |
| `source` | String | 可选 | 来源解析：`blogger` → 玩家 Blogger 数据；`lm_members#N` → 联盟成员列表 id==N |

> **来源解析（`resolve_character()`）**：优先取 `source` 对应的数据填充 `display`/`avatar`（有则用），无则保留角色表自身配置。
> **头像渲染规则（`_set_avatar()`）**：
> - `avatar` 为 `res://` 本地路径 → 同步 `load()` 显示图片
> - `avatar` 为 http(s) URL → 先显示色块，异步 `HTTPRequest` 下载后替换
> - 无 `avatar` → 显示圆角色块 + 名字首字，颜色取 `color`

### 2.2 对白场景文件 `data/dialogue/*.gd`

每个对白一个文件，`extends Node`，暴露单个变量 `dialogue`（字典）。

```gdscript
# data/dialogue/example.gd
extends Node

var dialogue = {
	"id": "example",
	"title": "联盟初见",
	"auto_interval": 3.0,          # 普通行自动跳转秒数（整句显示后计时）
	"background": "",              # 可选：背景图路径
	"after_finish": "",            # 可选：播完后跳转到的场景路径；空则发对话结束信号
	"lines": [
		{"speaker": "moran", "text": "你终于来了！"},
		{"speaker": "boy",   "text": "欢迎新博主！"},
		{"speaker": "moran", "text": "要加入我们的圈子吗？",
			"choices": [
				{"text": "当然要", "next": "join"},
				{"text": "先看看", "next": "decline"},
			]},
		{"label": "join",    "speaker": "player", "text": "求之不得！"},
		{"label": "join",    "speaker": "moran",  "text": "欢迎欢迎！"},
		{"label": "join",    "speaker": "boy",    "text": "以后多多关照！", "end": true},
		{"label": "decline", "speaker": "player", "text": "再考虑下吧……"},
		{"label": "decline", "speaker": "boy",    "text": "那随时欢迎你来~", "end": true},
	],
}
```

**对白行字段**：

| 字段 | 说明 |
|------|------|
| `speaker` | 说话人角色 `name` |
| `text` | 对白内容 |
| `duration` | 可选：单行覆盖自动间隔秒数 |
| `choices` | 可选：选项数组；存在则该行不自动跳转 |
| `label` | 可选：给该行打标签，供 `choices.next` / `goto` 跳转目标 |
| `end` | 可选：`true` 表示该行是对白/分支终点，播完即结束，不再顺序推进 |
| `goto` | 可选：该行播完后跳转到指定 `label`（用于分支汇聚/顺序跳转） |

**选项字段**：

| 字段 | 说明 |
|------|------|
| `text` | 选项显示文案 |
| `next` | 跳转目标：同文件内某行的 `label` |

> `next` / `goto` 指向 `label` 而非行号，避免增删行导致跳转失效。
> **分支终止**：`lines` 为线性数组，选择分支跳转到 `label` 后若不加 `end`/`goto`，会顺序掉进后续分支。每个分支末行须以 `end`（或 `goto`）收尾。

## 三、场景与脚本结构

### 3.1 对话场景 `scenes/dialogue.tscn` + `scripts/dialogue.gd`

```
dialogue.tscn
├─ 背景 TextureRect
├─ 聊天区 Control
│   ├─ 右侧头像 + 名字（player 靠右）
│   ├─ 左侧头像 + 名字（NPC 靠左）
│   └─ 中央对白框 PanelContainer
│       ├─ RichTextLabel        (整句直接显示)
│       ├─ 选项按钮列表 VBox     (仅带 choices 的行显示)
│       └─ 提示 Label            (右下角闪烁)
└─ 标题 Label （左上角，显示对白 title）
```

**关键流程（dialogue.gd）**：
1. `_ready()` 从 `DialogueManager` 读取当前对白 id → 取数据字典。
2. `_render_line()`：设置 `speaker` 头像/名字/位置（`speaker=="player"` 或角色 `side=="right"` → 右侧，否则左侧），填入正文。
3. 普通行：整句显示 → 启动 `auto_timer`；带 `choices` 行：不启动自动跳转，列出选项按钮。

### 3.2 交互规则

| 情况 | 行为 |
|------|------|
| 普通行超时 | 自动 `_advance()` 到下一条 |
| 空格键（`ui_accept`） | 立即 `_advance()` |
| 鼠标点击对白框 | 立即 `_advance()` |
| 选项行 | 不自动跳；显示选项（**↑↓ 聚焦 + 回车 / 鼠标点击**选择） |
| 选择 | 按 `next` 的 `label` 跳转 |
| 结束 | `after_finish` 非空 → 跳场景；否则发 `dialogue_finished(id)` 信号 |
| Esc（`ui_cancel`） | 强制退出，回到调用入口 |

**按键提示**：
- 普通行：右下角闪烁「**␣ 空格 / 点击 继续**」
- 选项行：「**↑↓ 选择 · 回车 确定**」

### 3.3 播放入口 `scripts/dialogue_manager.gd`

| 成员 | 说明 |
|------|------|
| `var current_id: String` | 当前播放对白 id |
| `func play(id)` | 设 `current_id`，`Utils.goto_scene("res://scenes/dialogue.tscn")` |
| `signal dialogue_finished(id)` | 对白正常播完（未指定 `after_finish`）时发出 |

### 3.4 调试试用场景 `tests/test_dialogue_scene.tscn` + `tests/test_dialogue_scene.gd`

- **F5 一进即自动播放一次示例对话** `DialogueManager.play("example")`。
- 对话结束 / Esc 退出后，显示调试面板：
  - 标题「对话调试工具」
  - `[播放示例对话]` 按钮：再次触发
  - `[返回主菜单]` 按钮：回主线场景
- 便于反复调试；对白播放中 Esc 可中断返回。

## 四、数据注册与热重载

- `data/dialogue_characters.gd` 注册进 `GDManager.data_configs`（key `dialogue_characters`），与既有数据一并 `reload_all_data()` 热重载。
- 各 `data/dialogue/*.gd` 通过 `GDManager.load_data(name, path)` 动态加载，同名热重载。
